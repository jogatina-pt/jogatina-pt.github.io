Criar atalho

  1. Abre este site no Safari.
  2. Toca no botão Partilhar (o quadrado com a seta para cima).
  3. Escolhe «Adicionar ao ecrã principal».

Fica com um ícone no ecrã inicial, como as outras apps, e abre sem barras do navegador. Também podes fazer isto dentro de cada jogo para teres um atalho só desse jogo.
