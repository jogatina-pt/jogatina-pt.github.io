# Jogatina

Jogos grátis para jogar com amigos, cada um no seu telemóvel: Panela de Pressão, Peta, Conversa de Tasca e Senhor Branco.

Site: https://ivomarcelopinto-png.github.io/jogatina/

O modo Clássico da Conversa de Tasca usa cartas traduzidas e adaptadas do Cards Against Humanity (CC BY-NC-SA 4.0), sem fins comerciais.
